Übersetzungsgrundsätze

Die Übersetzung folgt fünf Regeln, durch das ganze Werk durchgehalten:

  1. Einheitliche Kernbegriffe. Griechisches Vokabular wird mit festen Entsprechungen durchgehalten:
    πρόφασις → wahrer Grund · αἰτία → Vorwurf / Anschuldigung · στάσις → Bürgerkrieg · δύναμις → Macht · παρασκευή → Rüstung · δουλεία → Knectschaft
  2. Nichts hinzugefügt, nichts gesteigert. Keine Ausschmückungen, keine Übertreibungen.
  3. Nicht abschwächen. Wo Thukydides hart formuliert, bleibt es hart.
  4. Anmerkungen bei echten Zweifeln. Nur textkritische Unsicherheiten sind mit [Anm.: …] markiert.
  5. Griechische Ambiguitäten bleiben. Thukydides schrieb in scriptio continua ohne Worttrennung. Wo das Griechisch zwei Lesarten zulässt, lässt die Übersetzung beide zu.
