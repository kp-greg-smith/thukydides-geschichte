Source: [Google Fonts](https://github.com/google/fonts). Exact source revision, download URLs, and SHA-256 hashes are recorded in [manifest.json](manifest.json).

Almendra is the default. Missing characters fall back to the bundled Source Serif 4 and then the browser serif font. Files are loaded locally, only as needed; no font service is contacted by the reader.
